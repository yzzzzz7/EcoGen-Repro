# EcoGen-Repro

用于科研流程的输入来源与样本范围核验工具。完整命令及边界见 [README.md](README.md)。

它解决一个具体问题：输入 VCF、样本名单、参数或脚本已经改变，后续步骤却继续使用旧结果。

当前版本为 **0.1.0 alpha**，提供四个操作：

1. `lock`：记录配置、输入文件 SHA256 和样本范围。
2. `check`：检查当前文件是否仍与记录一致。
3. `run`：在运行指定命令前后核验输入，记录新输出的凭证。
4. `verify`：同时检查凭证、当前输入和输出文件。

支持普通文件、VCF/VCF.gz/VCF.bgz 表头以及逐行样本名单；精确匹配时检查样本顺序，使用子集时必须填写理由。参考基因组、BED、代码和环境锁定文件可作为普通文件登记。

运行时仅依赖 Python 标准库，不连接外部服务。示例全部为合成数据，不包含真实种群样本和未发表结果。

通过检查仅说明所声明文件的来源一致性，不说明分析方法、结果或生物学解释已经获得验证。外部软件版本是使用者声明，需要另行保留实际软件版本和诊断日志。大文件性能及外部实际使用尚未验证。

安装、合成示例、故障演示、配置规则和限制均在英文主文档中。已有锁、凭证和输出不会被自动覆盖。
