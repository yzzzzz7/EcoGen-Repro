# Roadmap

## Implemented in 0.1.0 alpha

- File-content and configuration locks.
- Ordered VCF/sample-list checks and documented subsets.
- Guarded command execution and portable output receipts.
- Synthetic examples, standard-library tests, and a CI workflow.

## Proposed next work

- Collect real user feedback on two independently reviewed workflows.
- Add narrowly scoped adapters when a user supplies a concrete format and failure case.
- Measure hashing overhead on large files and shared storage before making performance claims.
- Improve environment/version capture with explicit, reviewable commands.

These are plans, not completed validation, adoption, or funding commitments.

## Implemented in 0.2.0 alpha

- Installed-package offline walkthrough with expected drift rejections.
- HTML verification reports and full Chinese quickstart documentation.
- Installed-package demo and report checks in the CI matrix.
